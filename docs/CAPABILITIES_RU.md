# Vinci AI Pilot — матрица возможностей и демонстрация

Единый честный перечень того, что система умеет, с уровнем доказанности. Каждая строка выведена из
канонического кода, тестов, файла приёмки `docs/STAGE_F_ACCEPTANCE.md` и хроники `core/hot/recent.md`.
Ничего не преувеличено.

## Легенда статусов

| Статус | Значение |
|---|---|
| **LIVE-PROVEN** | Доказано живым прогоном в продакшне (реальные API, доставка в Telegram/Sheets). |
| **OFFLINE-PROVEN** | Доказано офлайн-регрессией ($0, без сети) на реальных узлах/фикстурах. |
| **IMPLEMENTED, NOT LIVE-VERIFIED** | Код есть и покрыт офлайн-тестами, но живого прогона именно этой ветки не было. |
| **OPTIONAL / DISABLED** | Реализовано, но выключено флагом по умолчанию; включение требует действий оператора. |
| **NOT IMPLEMENTED** | Не реализовано (план/будущее). |

## Активационные флаги (окружение)

Значения задаются в root-owned `/opt/n8n/n8n.env` (вне проекта). Ключевые:

- `MS_ENABLE_FIRECRAWL`, `MS_ENABLE_APIFY` — внешний сбор с сайтов/классифайдов.
- `MS_ENABLE_CLAUDE`, `MS_ENABLE_LLM_ANALYSIS`, `MS_ENABLE_LLM_SUMMARY`, `MS_ENABLE_LLM_PLANNER` — AI-слой (по умолчанию выключен).
- `MS_ENABLE_TELEGRAM`, `MS_ENABLE_TELEGRAM_COLLECTOR` — Telegram-шлюз и сбор из каналов.
- `MS_ENABLE_VK` **и** `MS_SOURCE_ALLOWLIST` (нужно добавить `vk`) — свежий сбор VK (по умолчанию оба выключены).
- `MS_MONITORING_ENABLED` — рекуррентный мониторинг (по умолчанию `false`).
- `MS_SOURCE_BUDGET_USD`, `MS_LLM_BUDGET_USD`, `MS_LLM_MAX_ANALYSES_PER_RUN` — бюджетные потолки.
- `MS_TELEGRAM_ALLOWED_USER_IDS`, `MS_TELEGRAM_WEBHOOK_SECRET` — доступ и безопасность шлюза.

## Листы XLSX-отчёта

`Сводка` · `Конкуренты` · `Офферы и цены` · `Сравнение источников` · `Аналитические выводы` ·
`Рекомендации` · `Боли и сигналы` · `Доказательства` · `Роль источника` · `Изменения` ·
`Качество данных` · `Технические данные` (скрытый).

Пустые необязательные листы опускаются при выгрузке; `Сводка` и `Технические данные` присутствуют всегда.
Даты — в московском времени (МСК, столбцы помечены «(МСК)»).

## Поведение при сбоях и известные ограничения

- Источник за антибот-стеной → честный `business_skip`/`irrelevant`, а не карантин; режим понижается прозрачно с русской причиной.
- Единичный источник, запрошенный как сравнение, → понижается до анализа (сравнение из одного источника не выдумывается).
- Универсальные заявления, не покрытые доказательствами всех участников, получают приписку «Подтверждено не для всех участвовавших источников».
- Рыночные «незанятые ниши» на малой выборке помечаются гипотезами.
- Свежий сбор VK и рекуррентный мониторинг по умолчанию выключены (см. выше).

## Честная демонстрация 5–10 минут (только доказанные возможности)

1. **Прямой анализ сайта.** Написать боту: «Проанализируй сайт `autolombardn1.ru`». Наблюдать: план → оценка стоимости → одобрение → сбор → отчёт в Telegram + XLSX; прогресс-сообщение редактируется до «✅ Готово».
2. **Сравнение двух конкурентов.** «Сравни `zalog24h.ru` и `autolombardn1.ru`». Показать лист «Сравнение источников» (каждое сравнение цитирует оба источника, без перекрёстной атрибуции).
3. **Синтез трёх источников.** «Сделай сводный анализ трёх автоломбардов Москвы». Показать `submit_synthesis`, 3 участника, «Режим данных: смешанный» при частичном повторном использовании.
4. **Повторное использование.** Повторить запрос по тому же сайту в пределах окна свежести → «💾 Использованы сохранённые данные», стоимость сбора $0.
5. **XLSX-выгрузка.** Открыть файл: даты в МСК, реальные URL в «Доказательствах», технические детали изолированы на скрытом листе.

Не демонстрировать как «работающее»: свежий сбор VK и рекуррентный мониторинг (выключены по умолчанию).
