# Воркфлоу 00 — Healthcheck Manual Test

**Язык:** Русский (технический гид для оператора)
**Файл:** `docs/N8N_WORKFLOW_00_HEALTHCHECK_RU.md`
**JSON-файл:** `n8n/workflows/00_healthcheck_manual_test.json`
**Статус:** ВЫПОЛНЕН УСПЕШНО — 2026-06-04
**Не изменять** — служит базовым healthcheck-эталоном для всего проекта

---

## Что проверяет этот воркфлоу

Это первый воркфлоу в системе. Его цель — убедиться, что n8n работает корректно:
- узлы соединяются и передают данные;
- Code-нод выполняет JavaScript без ошибок;
- на выходе формируется правильный JSON.

Никаких внешних API не используется. Никаких платных запросов. Только n8n + встроенный JavaScript.

---

## Почему начинаем без внешних API

Перед подключением Apify, Claude API, Google Sheets и Telegram важно убедиться,
что сама платформа (n8n) работает правильно: узлы соединены, данные передаются,
код выполняется без ошибок.

Если сразу подключить внешние сервисы и что-то пойдёт не так — непонятно,
где проблема: в логике воркфлоу, в credentials, в API или в самом n8n.

Healthcheck изолирует платформу и даёт уверенность перед следующим шагом.

---

## Структура воркфлоу

```
[Sticky Note 1]  →  [Manual Trigger]  →  [Edit Fields / Set]  →  [Code]  →  [Sticky Note 2]
```

| № | Узел | Тип | Назначение |
|---|------|-----|------------|
| 1 | Sticky Note | Sticky Note | Описание воркфлоу для оператора |
| 2 | Manual Trigger | Manual Trigger | Запуск вручную по кнопке |
| 3 | Edit Fields / Set | Set | Тестовые данные конкурента |
| 4 | Code | Code | Мок-анализ, имитирует будущий Claude API |
| 5 | Sticky Note | Sticky Note | Что означает результат и что будет дальше |

## Пошаговая сборка в UI n8n

### Шаг 1 — Создать новый воркфлоу

1. Открыть n8n через SSH-туннель: `http://localhost:5678`
2. В левом меню нажать **Workflows** → **+ New Workflow**
3. Кликнуть на заголовок воркфлоу (по умолчанию «My Workflow») и переименовать:

```
00 - Healthcheck Manual Test
```

4. Нажать **Save** (Ctrl+S).

---

### Шаг 2 — Добавить Sticky Note (узел 1)

1. В холсте нажать **+** или щёлкнуть правой кнопкой → **Add node**
2. В поиске ввести `Sticky Note` → выбрать узел
3. Поставить узел **левее** Manual Trigger (он не соединяется с цепочкой — это просто заметка)
4. Открыть узел и вставить текст:

---

**Текст Sticky Note 1 (скопировать как есть):**

```
🔧 HEALTHCHECK — Тестовый запуск

Этот воркфлоу проверяет, что n8n работает корректно.

Что происходит:
1. Manual Trigger — запуск вручную
2. Set — подставляем тестовые данные конкурента
3. Code — имитируем анализ (без Claude API)

Никаких внешних API. Никаких платных запросов.

Запусти воркфлоу и проверь вывод в последнем узле.
Если видишь JSON с полем "status": "analyzed" — всё работает.
```

---

### Шаг 3 — Добавить Manual Trigger (узел 2)

1. Нажать **+** на холсте → найти **Manual Trigger**
2. Узел не требует настройки — он просто запускает цепочку по кнопке
3. Разместить узел в начале цепочки

> Manual Trigger — это «кнопка запуска». В реальном воркфлоу его заменит Apify-триггер или расписание.

---

### Шаг 4 — Добавить Edit Fields / Set (узел 3)

1. После Manual Trigger нажать **+** на соединительной линии → найти **Edit Fields (Set)**
2. В узле переключить режим на **Manual mapping** (если предложат выбор)
3. Добавить поля одно за другим, нажимая **Add field**:

| Имя поля | Тип | Значение |
|----------|-----|----------|
| `platform` | String | `test` |
| `source_url` | String | `https://example.com/test` |
| `company_name` | String | `Test Competitor` |
| `text_context` | String | `Компания предлагает кредит под залог автомобиля. Решение за 1 день. Работаем по Москве и области.` |
| `parsed_at` | String | `2026-06-04` |

4. Убедиться, что переключатель **Keep Only Set** выключен (чтобы не потерять другие поля, если появятся).

**Итоговый JSON на выходе Set-узла:**

```json
{
  "platform": "test",
  "source_url": "https://example.com/test",
  "company_name": "Test Competitor",
  "text_context": "Компания предлагает кредит под залог автомобиля. Решение за 1 день. Работаем по Москве и области.",
  "parsed_at": "2026-06-04"
}
```

---

### Шаг 5 — Добавить Code (узел 4)

1. После Set-узла нажать **+** → найти **Code**
2. Убедиться, что выбран режим **Run Once for All Items** (или **Run Once for Each Item** — оба подходят для одного элемента)
3. Очистить содержимое редактора и вставить следующий код:

```javascript
const item = $input.first().json;

return [
  {
    json: {
      ...item,
      entity_type: "competitor",
      service_type: "secured_auto_loan",
      quality_score: 75,
      reason: "Test record processed successfully",
      status: "analyzed"
    }
  }
];
```

4. Нажать **Test step** — в панели справа появится результат выполнения.

**Ожидаемый вывод Code-узла:**

```json
{
  "platform": "test",
  "source_url": "https://example.com/test",
  "company_name": "Test Competitor",
  "text_context": "Компания предлагает кредит под залог автомобиля. Решение за 1 день. Работаем по Москве и области.",
  "parsed_at": "2026-06-04",
  "entity_type": "competitor",
  "service_type": "secured_auto_loan",
  "quality_score": 75,
  "reason": "Test record processed successfully",
  "status": "analyzed"
}
```

## Диагностика ошибок

| Симптом | Вероятная причина | Решение |
|---------|-------------------|---------|
| Code-узел красный, ошибка синтаксиса | Лишняя запятая или кавычка в коде | Скопировать JS заново из этого файла |
| Set-узел не сохраняет поля | Не нажата кнопка Save внутри узла | Убедиться, что каждое поле добавлено через Add field |
| Воркфлоу не запускается | Manual Trigger не соединён с Set | Соединить узлы стрелкой |
| Пустой вывод | `$input.first()` не нашёл элемент | Убедиться, что Set-узел выше в цепочке и выдаёт хотя бы один item |

## Импорт через JSON

Вместо ручной сборки узлов можно импортировать готовый воркфлоу из файла.
Файл: `n8n/workflows/00_healthcheck_manual_test.json`

---

### Способ 1 — Импорт из файла

1. Открыть n8n через SSH-туннель: `http://localhost:5678`
2. В левом меню нажать **Workflows**
3. Нажать кнопку **⋮** (три точки) или кнопку **Import** в правом верхнем углу
4. Выбрать **Import from File**
5. Указать файл `n8n/workflows/00_healthcheck_manual_test.json` с VPS или локальной копии
6. Нажать **Import**
7. Воркфлоу появится в списке с именем `00 - Healthcheck Manual Test`

> Если кнопки Import нет на главном экране — войди в любой воркфлоу, нажми **⋮** → **Import from File**.

---

### Способ 2 — Импорт из буфера обмена

1. Скопировать содержимое JSON-файла в буфер обмена:
   ```bash
   cat n8n/workflows/00_healthcheck_manual_test.json
   ```
   Выделить весь вывод и скопировать (Ctrl+A → Ctrl+C).

2. В n8n нажать **⋮** → **Import from Clipboard** (или **Paste from Clipboard**)
3. Нажать **Import**

---

### Как запустить Manual Trigger после импорта

1. Открыть воркфлоу `00 - Healthcheck Manual Test`
2. Убедиться, что воркфлоу **не активирован** (переключатель в правом верхнем углу должен быть выключен)
3. Нажать кнопку **Test workflow** (или кнопку **▶** на узле Manual Start)
4. Дождаться выполнения — узлы подсветятся зелёным

---

Кликнуть на узел **Mock Marketing Analysis** → вкладка **Output**.
Должен появиться следующий JSON (1 item):

  "platform": "test",
  "source_url": "https://example.com/test",
  "company_name": "Test Competitor",
  "text_context": "Компания предлагает кредит под залог автомобиля. Решение за 1 день. Работаем по Москве и области.",
  "parsed_at": "2026-06-04",
  "entity_type": "competitor",
  "service_type": "secured_auto_loan",
  "quality_score": 75,
  "reason": "Test record processed successfully",
  "status": "analyzed"

Критерий успеха: поле `"status": "analyzed"` присутствует и нет красных узлов.

---

### Что делать, если импорт не работает

| Проблема | Вероятная причина | Решение |
|----------|-------------------|---------|
| «Invalid JSON» при импорте | Файл скопирован не полностью | Скопировать весь файл от `{` до `}` включительно |
| Воркфлоу импортировался, но узлы не видны | Нужно прокрутить/зумировать холст | Ctrl+Shift+H (сбросить вид) или Ctrl+- для уменьшения масштаба |
| Узел Set показывает предупреждение | Версия n8n ниже 1.x | Пересоздать узел вручную по гиду выше (Шаг 4) |
| Code node — ошибка «$input is not defined» | n8n очень старой версии | Заменить `$input.first().json` на `items[0].json` и поменять `typeVersion` на 1 |
| Импорт завершился, но воркфлоу не активен | Это нормально — активировать не нужно | Запускать через «Test workflow», не через активацию |
