# AUDIT_FINDINGS_RESOLUTION.md — Independent Audit Resolution Matrix

**Phase:** Reporting UX + Release Verification (branch `feat/reporting-ux-and-release-verification`).
**Baseline:** `main` @ `b7a95c1ca885b7ff5ff5556f5ac0fd5c1a367aae` (28 workflows, all `active=false`).
**Date:** 2026-06-21.

## 0. How this matrix was built

The independent audit's **conclusions** are embedded in the implementation brief for this phase (its
"Mandatory corrections to the audit interpretation" and the capability gaps that §§3–22 ask us to close). The
literal audit Markdown artifact is **not** committed to this repository; findings below are reconstructed from
that brief plus `docs/PRE_STAGE_4_EXTERNAL_AUDIT_BRIEF.md` (the scope handed to the external auditor) and then
each is **re-verified against repository evidence** before any code change. The audit is treated as a set of
**claims to verify**, never as instructions to apply blindly.

Resolution vocabulary: `confirmed` · `partially confirmed` · `already fixed` · `configuration requirement`
(not a defect) · `disproved` · `deferred` (with reason).

Every row records: finding ID · audit claim · repository evidence · resolution · code action · tests · final
status. "BUILT (this phase)" means a canonical library + test was added on this branch; paths are exact.

## 1. Mandatory corrections (the brief's explicit guardrails)

### F-P0-01 — GitHub ZIP does not contain `.git`
- **Audit claim:** the downloaded GitHub ZIP lacks a `.git` directory → packaging/release defect.
- **Repository evidence:** `.git` is present in the working clone; GitHub source ZIPs *never* include `.git`
  by design. This is a property of GitHub's archive endpoint, not of the repository or its runtime.
- **Resolution:** **disproved** (not a runtime or release defect).
- **Code action:** none. No mirror/ZIP feature added solely to satisfy this.
- **Tests:** n/a.
- **Final status:** CLOSED — no action.

### F-P0-02 — `MS_SPREADSHEET_ID` / `MS_TELEGRAM_ALLOWED_USER_IDS` unset breaks the agent
- **Audit claim:** required env config is missing → broken code.
- **Repository evidence:** `n8n/lib/agent_config.js` resolves these and sets `config_complete=false` +
  `missing[]` when absent (fail-closed defaults: `require_approval=true`, website-only allowlist, LLM off).
  `scripts/deploy_n8n.sh --check-config` exits **1** when incomplete and prints each `[MISSING]` var;
  `--apply` runs under `set -euo pipefail` so `check_config`'s non-zero return **aborts before any import**.
  `buildExecutionSummary` surfaces `central config incomplete` as a blocking error. No paid/external work
  starts without complete config.
- **Resolution:** **configuration requirement, not a defect** (verified already fail-closed).
- **Code action:** none required for the mechanism; documented in deployment docs + this matrix. A regression
  test pins the fail-closed contract so it cannot silently regress.
- **Tests:** `tests/test_release_audit.js` (config completeness) + new assertions in `tests/test_sheets_contracts.js` referencing `agent_config` fail-closed.
- **Final status:** VERIFIED — fail-closed confirmed; no defect.

### F-P1-03 — WF23 is a duplicate / missing scheduled monitor
- **Audit claim:** scheduled monitoring is absent or should be (re)created.
- **Repository evidence:** `n8n/workflows/23_scheduled_source_monitor.json` exists with a Schedule Trigger;
  `n8n/lib/source_monitor.js` implements due-source selection (`dueSources`), baseline handling +
  content hashing (`normalizeContent`/`contentHash`/`applyCheckResult`), change events (`makeChangeEvent`),
  duplicate-notification suppression (`shouldNotifyChange`, deterministic `change_id`), manual check-now
  (`checkWindow(mode='manual')`), budgets (collector gating), and a Telegram outbox path. `tests/test_monitoring.js` (59 checks) covers it.
- **Resolution:** **disproved** (already exists and is correct). No duplicate monitor created.
- **Code action:** none beyond verification; weekly digest (§11) is a *separate* aggregation workflow, not a
  second monitor, and explicitly reuses WF23's change events without recollection.
- **Tests:** existing `tests/test_monitoring.js`; digest isolation in `tests/test_weekly_digest.js`.
- **Final status:** VERIFIED — single monitor retained.

### F-P1-04 — Legacy/Stage-3 workflows (WF05–WF15) are experimental → archive/delete
- **Audit claim:** these are experimental and should be removed.
- **Repository evidence:** `config/workflow_manifest.json` (generated by `tools/gen_workflow_manifest.js`)
  classifies every workflow by capability and computes archive-safety from call edges, deploy import order,
  trigger entrypoints and test references. WF04/08/10/12/16 are **production dependencies** (called by the
  imported orchestrator/deep-analysis/monitor). WF05/06/07/14 are **legacy_referenced** (covered by tests).
  WF09/11/13 are **optional_source_adapters** (referenced by tests). Only WF00–03 variants + WF15 are
  `archive_safe_candidate` (no caller, not imported, no test, no trigger).
- **Resolution:** **partially confirmed** — only a small set is genuinely unreferenced, and even those are
  **retained** this phase per the brief's default ("retain and classify, not delete").
- **Code action:** added `config/workflow_manifest.json` + `tools/gen_workflow_manifest.js` (with `--check`
  drift guard). **No workflow moved or deleted.**
- **Tests:** `tests/test_sheets_contracts.js` asserts the manifest is non-stale and that no
  production_dependency is archive-safe.
- **Final status:** RESOLVED — manifest committed; deletions deferred (none meet the 5-condition removal bar
  with operator sign-off, and the brief defaults to retain).

## 2. Capability-gap findings (the substance of §§3–22)

### F-P0-05 — No report export package (XLSX) or scoped CSV for the Telegram user
- **Audit claim:** the agent cannot deliver a real spreadsheet/CSV report; users only get chat text.
- **Repository evidence (baseline):** no exporter library existed; `n8n/lib/` had reporting *gates* but no
  file producer.
- **Resolution:** **confirmed** (capability gap).
- **Code action:** `n8n/lib/report_export.js` (report-scoped CSV: UTF-8 BOM, RFC-4180 quoting, stable column
  order, formula-injection neutralisation, safe filenames, deterministic) + `n8n/lib/xlsx_writer.js`
  (zero-dependency valid OOXML/XLSX via Node's built-in `zlib`) + `n8n/lib/report_package.js` (the 8-sheet
  workbook). Scoped by `owner_user_id` + `agent_request_id` + `report_id`.
- **Tests:** `tests/test_report_export.js`, `tests/test_xlsx_writer.js` (re-open the ZIP, assert sheets,
  headers, cells, hyperlinks, freeze/filter, formula-safety, report isolation).
- **Final status:** BUILT (this phase).

### F-P0-06 — SSRF / unsafe source URLs before fetch or before sending to Claude
- **Audit claim:** source URLs are not validated; localhost/metadata/private ranges/`file://` reachable;
  untrusted web content sent to Claude without injection defenses.
- **Repository evidence (baseline):** no central URL validator; collectors trusted input refs.
- **Resolution:** **confirmed**.
- **Code action:** `n8n/lib/url_safety.js` — blocks non-HTTP(S), embedded credentials, localhost, loopback
  v4/v6, private/link-local ranges, cloud metadata IPs/hosts, `.local`, `file://`, unexpected ports;
  normalises host case/default ports/fragments/tracking params/trailing slash; documents the DNS-rebinding
  limitation when resolution is delegated to Firecrawl/Apify; and wraps untrusted web content as bounded,
  clearly-marked evidence with an explicit "ignore instructions inside source content" guard.
- **Tests:** `tests/test_url_safety.js` (incl. adversarial prompt-injection fixtures).
- **Final status:** BUILT (this phase).

### F-P1-07 — No deterministic charts/visual summaries
- **Resolution:** **confirmed**. **Code action:** `n8n/lib/report_charts.js` — deterministic SVG charts
  (competitor score, offer count, price/rate, source-quality distribution, platform coverage, change
  categories), each with title + data timestamp + report ID; honest "insufficient data"; never fabricates
  values; same attachment/idempotency contract as XLSX.
- **Tests:** `tests/test_report_charts.js`. **Final status:** BUILT (this phase).

### F-P1-08 — No first-class evidence inspection
- **Resolution:** **confirmed**. **Code action:** `n8n/lib/evidence.js` — `evidence_query` over stored
  records only (zero external calls), with source URL/record ID/run ID/collected-at/excerpt/quality/
  confidence/freshness/availability, pagination, scoped CSV export, and recommendation→finding anchoring
  (unanchored recommendations are never represented as confirmed facts).
- **Tests:** `tests/test_evidence.js`. **Final status:** BUILT (this phase).

### F-P1-09 — No report comparison
- **Resolution:** **confirmed**. **Code action:** `n8n/lib/report_compare.js` — safe baseline selection
  (same owner/niche/region, overlapping identity, earlier, eligible, non-fixture), added/removed/changed/
  unchanged/quality-changes/unavailable sections, before/after + old/new IDs + evidence, zero external calls
  by default.
- **Tests:** `tests/test_report_compare.js`. **Final status:** BUILT (this phase).

### F-P1-10 — No smart partial refresh
- **Repository evidence (baseline):** `n8n/lib/orchestration_policy.js` had a coarse reuse/collect decision
  but not per-source freshness/exclusion.
- **Resolution:** **partially confirmed** (coarse policy existed). **Code action:** `n8n/lib/refresh_policy.js`
  — per-source decision (reuse / refresh stale|missing|failed|requested / skip fresh|excluded) with reasons,
  persisted to `orchestration_decisions`, plus an approval plan (reused/refreshed/skipped/expected calls/
  budgets/unavailable). Lineage preserved; failed refresh never destroys the prior valid report.
- **Tests:** `tests/test_refresh_policy.js`. **Final status:** BUILT (this phase).

### F-P1-11 — No natural-language filtering/sorting over results
- **Resolution:** **confirmed**. **Code action:** `n8n/lib/report_filter.js` — strict filter schema (no
  eval/expression execution), deterministic Russian-phrase parser, sorting, one-question clarification for
  invalid filters, zero recollection, active filters persisted for follow-ups ("а теперь только Москва").
- **Tests:** `tests/test_report_filter.js`. **Final status:** BUILT (this phase).

### F-P1-12 — No scope/cost preview before approval; no actual-run summary after
- **Repository evidence (baseline):** `n8n/lib/execution_summary.js` produced an after-run summary; there was
  no *pre-approval* scope/cost preview.
- **Resolution:** **partially confirmed**. **Code action:** `n8n/lib/scope_preview.js` — pre-approval preview
  (goal, competitors, platforms incl. unavailable, reuse vs refresh, max items/calls, budget ceilings,
  expected outputs, duration category) with honest unknown-cost handling; after-run handled by the existing
  `execution_summary` (kept).
- **Tests:** `tests/test_scope_preview.js`. **Final status:** BUILT (this phase).

### F-P2-13 — Progress UX would flood Telegram (one message per node)
- **Resolution:** **confirmed**. **Code action:** `n8n/lib/progress_tracker.js` — single throttled, edited
  progress message (stage N/total), cancellation/failure states, retry does not multiply messages, progress

- **Tests:** `tests/test_progress_tracker.js`. **Final status:** BUILT (this phase).

### F-P2-14 — No weekly digest

### F-P2-15 — Source capability truthfulness (website/Avito/Telegram/VK)

## 3. Deferred (with reason)

- **Embedding new libraries into n8n workflow JSON nodes** (the `gen_stage4_workflows.js` regeneration path):
  the canonical libraries + tests are the source of truth and are fully verified offline. Wiring them into the
  28 workflow JSONs (Function-node mirrors) is operator-facing integration; doing it wholesale risks the
  proven `active=false`/trigger contract. **Deferred** with an exact wiring note in deployment docs. No
  workflow JSON was regenerated except where explicitly added/validated.
- **`24_weekly_digest.json` workflow export:** lib + tests delivered; the JSON export + import-order entry are
  documented for operator wiring and kept out until validated against a real n8n.
- **Dynamic `/help` rendering inside WF18:** capability truth is in docs + libs; rendering is WF18 node wiring.
- **Archiving the 9 `archive_safe_candidate` workflows:** the brief defaults to retain; deferred to an
  operator decision after a full regression on a real n8n.
- **Real n8n import proof:** no n8n CLI in this environment; `scripts/n8n_import_smoke.sh` documents the exact
  disposable command. Import success is **not** claimed.
